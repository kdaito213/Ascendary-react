# Ascendary

## 🇯🇵 日本語

### ■ 概要
Ascendaryは、ジャグリング（特にディアボロ）などのスキル習得における  
**「継続の難しさ」**を解決するための練習記録・可視化アプリです。

練習内容や成功率を記録し、成長を可視化することで、  
モチベーション維持と技術向上を支援します。

 アプリのリンク: https://ascendary-7ff38.web.app/

---

### ■ 課題（Problem）
スキル系の分野では以下の課題があります：

- 成長が実感しづらい
- フィードバックが少なくモチベーションが低下する
- 記録が面倒で継続できない

その結果、多くの人が途中で離脱してしまいます。

---

### ■ 解決策（Solution）
Ascendaryでは以下の仕組みで解決します：

- **簡単な練習記録機能**  
  最小限の操作で記録可能にし、継続しやすく設計

- **成功率の管理**  
  技ごとの達成度を定量的に把握

- **可視化機能**  
  グラフによって成長を直感的に確認

- **ユーザー認証**  
  個人ごとのデータ管理

---

### ■ 主な機能

- 練習記録の作成・管理
- 技ごとの成功率管理
- 履歴データの可視化
- ログイン / 新規登録機能

---

### ■ 技術スタック

- フロントエンド: React  
- バックエンド: Firebase  
- データベース: Firestore  
- ホスティング: Firebase Hosting  

---

### ■ 工夫した点

- **「続けられること」を最優先にした設計**
- 実際のユーザー（部活動メンバー等）にテスト利用してもらい、改善を反映
- 「記録の手間」という本質的な課題に対してUI/UXでアプローチ

---

### ■ 成果・学び

- 実ユーザーからのフィードバックをもとに改善サイクルを経験
- ユーザー視点でのプロダクト設計の重要性を理解
- 継続率向上には機能よりも体験設計が重要であると実感

---

### ■ 今後の展望

- ストリーク機能（継続日数の可視化）
- フレンド機能（相互モチベーション）
- 通知機能
- モバイルUXの改善

---

### ■ 開発背景

自身がディアボロプレイヤーとして、  
「成長が見えずモチベーションが続かない」という課題を実感したことがきっかけです。

実体験に基づいた課題解決を目的として開発しました。

## 🇺🇸 English

### ■ Overview
Ascendary is a web application designed to solve the problem of  
**difficulty in maintaining consistent practice** in skill-based activities such as juggling (diabolo).

It enables users to record and visualize their progress, improving  
motivation, consistency, and skill development.

---

### ■ Problem
In skill-based activities:

- Progress is often invisible
- Lack of feedback reduces motivation
- Recording practice is tedious

As a result, many users quit before reaching proficiency.

---

### ■ Solution
Ascendary addresses these challenges by:

- **Easy Practice Logging**  
  Designed for minimal friction to encourage consistency

- **Performance Tracking**  
  Track success rates per trick

- **Visualization**  
  Graph-based feedback to make progress visible

- **Authentication**  
  Secure user-specific data management

---

### ■ Key Features

- Practice record management  
- Success rate tracking  
- Data visualization  
- User authentication  

---

### ■ Tech Stack

- Frontend: React  
- Backend: Firebase  
- Database: Firestore  
- Hosting: Firebase Hosting  

---

### ■ What I Focused On

- Designing for **continuity over complexity**
- Solving a **real user problem**
- Iterating based on **actual user feedback**

---

### ■ Future Improvements

- Streak system  
- Social features  
- Notifications  
- Mobile UX improvements  

---

### ■ Background
This project was inspired by my own experience as a diabolo player,  
where I struggled to stay motivated due to invisible progress.
